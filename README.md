# Figma-focused responsive implementation

This version removes the unrelated pricing cards/form from the previous attempt and uses the supplied Figma assets directly.

Open `index.html` with VS Code Live Server.

Responsive states:
- Desktop: 821px and above
- Tablet/mobile navigation: 820px and below
- Small mobile: 480px and below

- index.html
- css/style.css
- js/script.js
- assets/* (copied from supplied Assets ZIP)
